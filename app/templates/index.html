The Assessment Method

Proof of understanding beats multiple-choice quizzes

Anyone can copy a coding tutorial or ask an LLM. Path2Work evaluates genuine competence through three progressive stages:

1 40% Weight

Build Phase

Write functional, working code or diagnostic configuration answering a real business brief. Attach a public repository URL or direct implementation.

Can they deliver working execution?
2 30% Weight

Explain Phase

Articulate architecture decisions, technical trade-offs, and security choices in plain English. Prove you understand the why, not just the copy-paste.

Can they explain their reasoning?
3 30% Weight

Adapt Phase

Requirements shift in real jobs: sudden load surges, schema revisions, or offline constraints. Adapt the solution to handle the unexpected.

Can they pivot when conditions change?

The 5-Tier Evidence Trust Ladder

Every badge states clearly what was actually examined. We never imply higher trust than the data supports.

LEVEL 1

Frequently Addressed Questions

Addressing core technical and practical assumptions for early-career IT.

Which IT roles are supported first?

We lead with the highest South African entry-level demand: Junior Software Developer, Junior Data Analyst, and Cloud / IT Support Specialist.

What proof do employers actually trust?

Employers inspect raw evidence: real repository code commits, technical explanation notes, and adaptation diffs rather than self-reported resume bullet points.

How do you prevent plagiarism or AI fraud?

The Adapt stage forces candidates to change architecture rules on short notice. Thin responses are scored down and flagged, and Level 5 requires direct employer review.
